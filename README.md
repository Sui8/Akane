# Akane

[Status](https://stats.uptimerobot.com/OLLN9UA6YG) | [Support Server](https://discord.gg/MK7VaeUCEe) | [サーバーに招待する](https://discord.com/oauth2/authorize?client_id=777557090562474044&permissions=8&scope=bot%20applications.commands)

サーバー管理機能、エンターテインメント機能を兼ね備えた多機能Discord Botです。

---

## Features
*   **Utility**: サーバー設定、各種情報取得、モデレーション補助
*   **Economy & Gambling**: Bot内通貨によるスロット等の娯楽機能
*   **Customization**: サーバーごとの設定やログ管理

## AI Usage
本プロジェクトでは、以下の生成AIを活用して作成したアセットを利用しています。
